portugueses. Fontes obtidas pelo npm com integridade verificada, sem adicionar
dependências ao projeto:

- `@fontsource-variable/space-grotesk@5.2.10`, arquivo
  `space-grotesk-latin-wght-normal.woff2`.

Licenças SIL Open Font License preservadas nos arquivos `*-LICENSE.txt`.
Ao substituir uma fonte, alterar a versão no nome e atualizar a referência CSS,
pois os arquivos são publicados com cache imutável.
